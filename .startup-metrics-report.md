### Three design decisions worth defending

1. **The halves stay apart.** Between "ingest has the first byte" and "an
   operator opened the tile" is dwell time belonging to neither pipeline. A
   joined total would be dominated by human reaction time. Publisher
   reconciles against job-start -> first-byte-at-ingest; player reconciles
   against `playback_ttff_ms`.
2. **A third state beyond measured/unmeasured.** SRT has no TCP connect (its
   caller handshake *is* the connect); raw MPEG-TS playback has no manifest.
   Calling those "unmeasured" sends an operator hunting for an impossible
   instrument, so they are `not_applicable`, and their time is attributed to
   the phase that genuinely contains it.
3. **A missing middle milestone unmeasures both neighbours.** Donating a
   missing handshake to `publish_accept` would read as a slow ingest — the
   exact misattribution this family exists to prevent. (This was a real bug in
   my first draft; caught by `test_missing_middle_milestone_unmeasures_both_neighbours`.)

### The laptop-leg blocker, precisely

It is **not** "the media file must exist on the API host" alone. There are two
independent gates in `web/api/main.py`, and the first one is what actually
bit:

1. **`main.py:705`** rejects any `media_path` ending in `dummy.mp4`, containing
   "big buck", or ending `/bbb` when `publisher_host=local`:
   *"VOD presets are for cloud encode only."* So the repo's standard fixture is
   rejected **by filename**, regardless of where it exists.
2. **`main.py:721`** then requires `os.path.exists(media_path)` **on the API
   host**, while the agent opens the same absolute path **on the laptop**. The
   laptop root (`/Users/sean/Developer/moq-test-tools`) and the VM root
   (`/opt/moq-test-tools`) differ, so a repo-relative path can never satisfy
   both.

**Workaround used:** copy the fixture to `/tmp/laptop-rtmp-qa.mp4` on *both*
hosts (identical 1774361 bytes). The path is absolute and identical on both, and
the filename dodges gate 1. `MEDIA=/tmp/laptop-rtmp-qa.mp4 scripts/qa_local_ttff.py`.

The durable fix (not done here) is for the API to skip the local-host existence
check when `publisher_host=local` and let the agent report a missing file —
the API is validating a path it does not own.
